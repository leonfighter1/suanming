# AI 生成内容标识规范 v0.1

Status: draft, pending legal review. Scope: every surface that shows
model-generated text, including reports, share images, push notifications
with generated text, consultation briefs, and Action Kits (Phase 3).

## Legal basis (confirm with counsel)

- **EU AI Act, Art. 50.** Transparency obligations apply from 2 August 2026.
  Art. 50(2) requires providers of AI systems that generate synthetic text,
  images or audio to mark the output in a machine-readable, detectable way.
  The user must also be told clearly that they are dealing with AI
  generated content.
- **Korea, Framework Act on AI (인공지능 기본법)**, in force 22 January 2026:
  advance notice that a product or service uses generative AI, and labelling
  of generated output.
- Elsewhere: no mandatory label yet. The matrix sets
  `visible_label: recommended`, and the machine-readable marker is always on.

The matrix (`geo_rule_matrix.json → ai_disclosure`) decides **visible**
labelling per region. Machine-readable marking is global.

## 1. HTTP API

Every response carrying model-generated content:

```
X-AI-Generated: true
X-AI-Model: <provider>/<model-id>;prompt=<prompt_version>
```

Deterministic endpoints (`POST /v1/charts`) **must not** send these headers.
Mixing them up would weaken the "facts are deterministic" differentiation in
the App Store review notes.

## 2. Report JSON

```json
"ai_disclosure": {
  "generated": true,
  "model": "anthropic/claude-…",
  "prompt_version": "narrative@12,action@7,guard@4",
  "label_required": true,
  "generated_at": "2026-10-25T12:00:00Z"
}
```

Only the interpretation and action layers are generated. The facts layer
(ChartFact restatement) and the expectation layer (fixed copy) are not, and
the client must keep that boundary visible.

## 3. Client display

- **Position:** a fixed label in the expectation-management layer at the
  bottom of every report, plus a small badge on the interpretation layer
  header.
- **Copy** (lives in the term table, not in the model prompt):
  - zh-Hant: 「本解讀由 AI 依據命盤資料生成，僅供娛樂和玄學學習使用。」
  - zh-Hans: 「本解读由 AI 根据命盘数据生成，仅供娱乐和玄学学习使用。」
  - en: "This interpretation was generated by AI from your chart data. It is
    for reflection only."
- `label_required: true`: the label can't be collapsed or hidden. Otherwise
  it is shown but may be collapsed.
- Korea: one-time notice before the first report that the service uses
  generative AI.

## 4. Share images and exported files

- Visible: the same label in the image footer, next to the watermark and
  disclaimer.
- Machine-readable: XMP/IPTC `DigitalSourceType = trainedAlgorithmicMedia`
  in PNG/JPEG metadata. Evaluate C2PA content credentials before Phase 3.
- PDF Action Kits: XMP metadata with the same fields plus a visible footer.

## 5. Tests (Phase 1)

- API contract test: headers present on `/v1/reports`, absent on
  `/v1/charts`.
- Render test: for EU/KR users the label is visible and not collapsible.
- Share image test: metadata field present after server-side render.
