# Modules

Registry of reusable modules (see the reuse-first skill). Search here before adding code.

| Capability                                  | Module                                                                                                                              | Use it for                                             | Don't                                                                             |
| ------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------ | --------------------------------------------------------------------------------- |
| ChartFact types, `SOURCE_LEVELS` (frozen)   | `src/chart-fact/types.ts`                                                                                                           | every engine output                                    | add a fifth source level                                                          |
| Canonical JSON                              | `src/chart-fact/digest.ts` `canonicalJson`                                                                                          | anything hashed or signed                              | `JSON.stringify` for hashing                                                      |
| Keyed input digest                          | `src/chart-fact/digest.ts` `inputDigest`                                                                                            | every engine's `input_digest`, cache keys              | hash birth data with plain SHA-256                                                |
| ChartFact validation                        | `src/chart-fact/validate.ts` `validateChartFact`                                                                                    | API responses, tests, CI                               | hand-written shape checks                                                         |
| Civil time → UTC, DST gap/fold              | `src/engines/bazi/time.ts` `localToUtc`                                                                                             | any birth-time input (bazi, astrology)                 | another tz converter, or a library's own tz handling                              |
| Equation of time, true solar time           | `src/engines/bazi/time.ts` `equationOfTimeMinutes`, `trueSolarMs`                                                                   | 真太阳时 anywhere                                      | a second EoT formula                                                              |
| 十神 / 十二长生                             | `src/engines/bazi/index.ts` `tenGod`, `diShi`                                                                                       | re-basing pillars on the day master                    | local copies of the tables                                                        |
| Bazi engine                                 | `src/engines/bazi/index.ts` `computeBazi`                                                                                           | `ChartFact(system=bazi)`                               | call lunar-javascript directly from other layers                                  |
| Unbiased DRBG                               | `src/engines/tarot/drbg.ts` `HmacDrbg`                                                                                              | any reproducible random draw                           | `Math.random`, modulo-biased ints                                                 |
| Tarot deck + spreads                        | `src/engines/tarot/deck.ts`                                                                                                         | card ids, default names                                | card lists elsewhere (UI names come from the term table)                          |
| Tarot draw / audit replay                   | `src/engines/tarot/index.ts` `computeTarot`, `verifyDraw`                                                                           | draws and audits                                       | store seeds                                                                       |
| Astrology positions (POC)                   | `src/engines/astrology/index.ts` `computeAstrology`                                                                                 | `ChartFact(system=astrology)`                          | @gitstrology/engine (rejected, ADR-0001)                                          |
| Compliance rule layer                       | `src/compliance/rules.ts` `compileRules`, `scan`                                                                                    | every model/teacher/kit output before render           | inline regex checks                                                               |
| Geo-Rule resolution                         | `src/compliance/geo.ts` `resolveRegion`                                                                                             | before any model call                                  | per-feature country `if`s                                                         |
| Demo handlers (CLI + web UI)                | `src/demo/handlers.ts` `runBazi`, `runTarot`, `runAstro`, `runGuard`                                                                | any manual/demo surface over the engines               | call engines directly from a new demo                                             |
| Local demo server                           | `src/demo/server.ts` `createDemoServer`                                                                                             | `npm run demo:ui`, API tests                           | a second HTTP wrapper for demos                                                   |
| AI report pipeline                          | `src/ai/pipeline.ts` `generateReport`                                                                                               | every AI interpretation (app, demo, batch)             | call a model directly from a feature                                              |
| LLM providers                               | `src/ai/providers/deepseek.ts` `DeepSeekProvider`, `providers/anthropic.ts` `AnthropicProvider`, `providers/mock.ts` `MockProvider` | model calls; offline tests and demos                   | a second SDK wrapper                                                              |
| Versioned prompts                           | `src/ai/prompts.ts` `PROMPTS`                                                                                                       | agent system prompts + user-message builders           | edit a prompt in place (bump the version)                                         |
| Model routing                               | `config/model_routing.json` + `src/ai/routing.ts` `routeFor`                                                                        | choosing model/effort per agent and locale             | hard-coded model ids                                                              |
| Protected terms                             | `i18n/terms.json` + `src/ai/terms.ts` `term`, `normalizeTerms`                                                                      | any display of engine terms (UI via `/api/terms`)      | per-screen term maps                                                              |
| Deterministic report layers                 | `src/ai/layers.ts` `factsLayer`, `expectationLayer`                                                                                 | facts and expectation layers                           | let the model restate facts                                                       |
| 流年 / 加权五行 / 冲合                      | `src/engines/bazi/index.ts` `yearGanZhi`, `weightedWuxing`, `branchRelations`                                                       | any year pillar or element score                       | recompute 干支 years elsewhere                                                    |
| Chart request validation + engine dispatch  | `src/service/charts.ts` `computeChart`, `InputError`                                                                                | v1 API, demo, any new entry point                      | validate birth input again elsewhere                                              |
| Runtime wiring (secrets, providers)         | `src/service/runtime.ts` `loadSecrets`, `buildProviders`, `upstreamMessage`                                                         | any process that runs engines or the AI pipeline       | read provider keys or secrets ad hoc                                              |
| HTTP helpers                                | `src/http/util.ts` `readJson`, `send`, `problem`, `aiHeaders`                                                                       | every Node HTTP server                                 | per-server body parsing or AI headers                                             |
| v1 API                                      | `src/api/server.ts` `createApiServer`, `publicReport`; `src/api/store.ts` `Store`                                                   | product API; the user-visible report view              | expose internal report fields                                                     |
| App ← server sync                           | `scripts/app-assets.ts` (`npm run sync:app`)                                                                                        | terms, deck/positions, topics, test fixtures in `app/` | hand-edit files under `app/assets/i18n`, `app/test/fixtures`, `app/lib/generated` |
| Flutter API client + models                 | `app/lib/data/api_client.dart`, `app/lib/domain/models.dart`                                                                        | all App ↔ API calls                                    | call `http` from widgets                                                          |
| Flutter report layers                       | `app/lib/presentation/widgets/four_layer_report.dart` (`FourLayerReport`, `ExpectationFooter`)                                      | every report screen                                    | render the AI label elsewhere                                                     |
| Auth (passwords, tokens, social, limits)    | `src/auth/service.ts` `AuthService`, `tokens.ts` `TokenService`, `social.ts` `SocialVerifier`, `limits.ts`                          | every sign-in path and bearer check                    | hash passwords or verify JWTs elsewhere                                           |
| App token storage + auth state              | `app/lib/data/token_store.dart`, `app/lib/application/providers.dart` `authProvider`                                                | anything that needs the signed-in user                 | read secure storage directly                                                      |
| 农历 date                                   | `src/engines/bazi/index.ts` `lunarDate` (+ `GET /v1/calendar/lunar`)                                                                | any 农历 display or preview                            | call lunar-javascript for dates elsewhere                                         |
| Pipeline progress                           | `PipelineDeps.onProgress` in `src/ai/pipeline.ts`                                                                                   | live status of long AI jobs                            | fake progress timers                                                              |
| App design system                           | `app/lib/presentation/design.dart` (`Space`, `Radii`, `AppCard`, `HeroBanner`, `Pill`, `FadeSlideIn`)                               | every screen's layout and motion                       | ad-hoc paddings, cards or entrance animations                                     |
| App profiles (device only)                  | `app/lib/domain/profile.dart`, `app/lib/data/profile_store.dart`, `profilesProvider`                                                | default + other people's birth data                    | send names to the server                                                          |
| Shared birth inputs                         | `app/lib/presentation/profiles_page.dart` `BirthFields`, `LunarPreview`                                                             | profile editor and 八字 form                           | duplicate date/city/gender inputs                                                 |
| Report export                               | `app/lib/domain/export.dart` `exportReportMarkdown`                                                                                 | download/copy/share of readings                        | build export text elsewhere                                                       |
| 农历 ↔ 公历, 时辰 options                   | `src/engines/bazi/index.ts` `lunarMonths`, `lunarToSolar`, `shichenOptions` (+ `/v1/calendar/*`)                                    | date and time pickers, conversions                     | convert calendars in the app                                                      |
| Birth input basis                           | `facts.input_basis` (`InputBasis` in `src/engines/bazi/index.ts`)                                                                   | telling UI and AI how precise the birth moment is      | infer precision from the time value                                               |
| Dev test accounts                           | `src/service/runtime.ts` `DEV_ACCOUNTS`, `seedDevAccounts`                                                                          | local testing (admin/admin)                            | create test users any other way                                                   |
| App 农历 / 时辰 pickers                     | `app/lib/presentation/profiles_page.dart` `LunarDatePicker`, `ShichenPicker`                                                        | any birth date/time input                              | re-implement pickers per screen                                                   |
| 八字 independent oracle + differential test | `test/oracle/bazi-oracle.ts`, `test/oracle/compare.ts` (`npm run verify:bazi`)                                                      | checking any engine change                             | trust a single implementation                                                     |
| 塔羅 statistical battery                    | `test/oracle/tarot-stats.ts` `tarotBattery` (`npm run verify:tarot`)                                                                | checking any draw/RNG change                           | ad-hoc randomness checks                                                          |
| AI faithfulness checks                      | `src/ai/faithfulness.ts` `checkFaithfulness`, `scripts/eval-ai.ts`                                                                  | evaluating real model output                           | eyeballing reports only                                                           |
| Trend scores (八字)                         | `src/ai/trend.ts` (`trendSchema`, `checkTrend`, `trendLayer`); app `widgets/trend_chart.dart` `TrendCard`                           | any per-period score chart                             | let the model compute totals or invent periods                                    |
| 破除運勢 plans                              | `src/ai/remedy.ts` `generateRemedy`; API `/v1/reports/{id}/remedies`; app `widgets/remedy.dart` `openRemedy`                        | paid per-topic add-ons                                 | a second purchase or generation path                                              |
| Printing                                    | `app/lib/platform/printer.dart` `printHtml`, `printableHtml`                                                                        | printing any text document                             | `window.print()` on the whole app                                                 |
| Compact buttons in rows/dialogs             | `app/lib/presentation/widgets/remedy.dart` `compactButtons`                                                                         | buttons inside Row / Wrap / dialogs                    | per-button minimumSize hacks                                                      |
